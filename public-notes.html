ทดลองให้เข้าใจ และช่วยกันตรวจให้ดีขึ้น

เครื่องมือนี้ใช้กรณีสมมติเพื่อสำรวจความสัมพันธ์ระหว่างพื้นที่ โมเดล เอกสาร คน และการตัดสินใจ เปิดให้ตั้งคำถามและแจ้งข้อคลาดเคลื่อนได้ ข้อแก้ไขที่มีบริบทช่วยพัฒนาเนื้อหาได้มากกว่าการนับคะแนนว่าฝ่ายใดถูก

สิ่งที่ตั้งใจให้ทดลองได้

  • 14 ช่วงงาน / 42 ปัญหา / 237 รายการไฟล์ / 24 อุปกรณ์ตัวแทน; แต่ละช่วงเป็น case context ไม่ใช่ทุก package เปลี่ยน phase พร้อมกัน
  • 3D canvas พร้อม 19 service assemblies และความสัมพันธ์ zone / asset / file; Zone Quest ทดลอง adjacency; 5 เคส Work control; 7 บทเรียน architecture / materials / environment
  • revision-aware evidence, read-access policy, scoped requests และ ROI scenario ใช้เพื่อทดลองเหตุผลของการผ่านหรือหยุด ไม่ใช่ผลอนุมัติโครงการจริง

12 MW กับสิ่งที่เห็นในโมเดล

12 MW IT เป็นโจทย์โปรแกรมสมมติจาก 2 × 500 racks × 12 kW ไม่ใช่ facility demand หรือผล sizing. ภาพเป็น teaching geometry แบบย่อ ไม่ได้จัดวางครบ 500 racks ต่อ Hall และไม่ผ่านการตรวจพื้นที่จริง

4000 A ที่ 400 V, PF 0.95 แปลงเป็นกำลังสามเฟสเชิงอุดมคติประมาณ 2,633 kW; route ที่เห็นตั้งโหลดตัวอย่าง 1,800 kW. CHW header 2,400 kW แสดงเพียงบางส่วน ไม่ใช่ระบบที่พิสูจน์ว่ารองรับ 12 MW. ไม่บวก main + branch หรือ supply + return ซ้ำ ไม่บวก feed A/B เป็นโหลด rack สองเท่า

ขนาด น้ำหนัก clearances ฉนวน route และรูปทรงเป็น teaching assumptions. ไม่มี protection coordination, short-circuit, derating, hydraulic network, capacity balance, fire strategy, load/structural check, PUE, availability, Tier หรือ redundancy certification

ISO / CDE / สิทธิ์

รูปแบบโฟลเดอร์ ชื่อ 7 fields รหัส revision Rxx ผู้มีอำนาจ และ policy originator-review เป็นข้อกำหนดของบทเรียน ไม่ใช่รหัสหรือ hierarchy ที่ ISO บังคับทุกโครงการ. WIP / Shared / Published / Archive ไม่ใช่ phase และคำว่า Published อย่างเดียวไม่อนุญาตให้ใช้ก่อสร้าง

อ่านได้ ≠ เข้าไซต์ได้ ≠ มีอำนาจเริ่มงาน. ทุกคนสลับบทบาทเองได้ ไม่มี authentication, tamper-proof audit หรือ security enforcement. ข้อมูลสมมติและ payload ทั้งหมดเป็น public static assets; การซ่อนใน UI ไม่ใช่การรักษาความลับ อย่าใส่ข้อมูลโครงการจริง

อ้างหลักคิดจาก UK BIM Framework Guidance Part C, Edition 1 (2020); ตรวจมาตรฐาน ฉบับที่ใช้ national annex และ appointments ของงานจริงต่อ ไม่ใช่ ISO compliance certification

สถาปัตย์และสภาพแวดล้อม

พื้น ผนัง ฝ้า หลังคา façade ประตู และทางเข้าถึงมีตัวอย่างชั้นวัสดุ 3D แยกจาก campus. ผิวบางรายการเชื่อมได้เพียงระดับโซน ประตูเชื่อม service assembly ที่มีอยู่ ยังไม่แก้ native model / face material หรือ export detailed IFC

ทิศแดด มุมเงย ลมและฝนตั้งโดยผู้เล่น ไม่มีพิกัด วันเวลา สภาพอากาศ หรือ georeference จริง จึงไม่ใช่ sun-path, shadow, thermal, CFD, runoff, wind-uplift หรือ accessibility compliance calculation

ตัวเลข layer thickness เป็นสมมติ ไม่ให้ rating จากวัสดุชิ้นเดียว. ต้องตรวจ assembly และ interface ที่ตรงเงื่อนไขงาน. Technical recommendation ของ ARC ในเกมไม่ใช่ Approved for Construction; รายการหลักฐานเป็น simulated attestations ไม่ใช่ผลทดสอบจริง. UL: door assemblies · GSA: EPD ไม่ได้แปลว่า environmentally superior

งานซ่อม / ROI / Digital Twin

วัน PM และหน้าที่ใน Work control เป็นสมมติ ใช้นาฬิกาจำลองแยกจาก lifecycle / warranty timeline. ไม่มีการตรวจบุคคลจริง การแยกพลังงาน หรือการสั่งงานอุปกรณ์. เอกสารเชื่อมใช้ policy ของ CDE แต่ปุ่ม maintenance ไม่ตรวจความใช้ได้ของ manual revision หรือหลักฐานจริง. OSHA 1910.147 ใช้ประกอบหลักคิดเรื่องหน้าที่ ไม่ใช่ procedure งานไฟฟ้าหรือการรับรองตามกฎหมายไทย

Risk points เป็น severity-weighted open backlog ไม่ใช่ probability × consequence หรือค่าความเสี่ยงวิศวกรรมที่ validate แล้ว. ROI มาจากสมมติฐานที่ปรับเอง ไม่ใช่ measured savings. Twin เป็น synthetic data-trust examples ไม่มี live BMS/EPMS/OT และไม่มี feedback control loop

ไฟล์ การใช้งาน และความเป็นส่วนตัว

IFC4 ที่ดาวน์โหลดเป็น 24 identity proxy boxes; BCF 2.1 เป็น 3 issues; JSON/PDF มี payload จริง. รายการ .rvt/.dwg และ native formats อื่นเป็นทะเบียนสมมติ ไม่มี binary ให้เปิด. IFC schema / geometry และ BCF XSD checks ไม่แทนการทดลองใน receiving commercial viewer

แอปไม่ใส่ analytics หรือส่ง session/notes ไป server แต่ผู้ให้บริการ hosting อาจมี access logs ตามบริการของเขา. localStorage ใช้จำผลทดลองใน browser/origin นี้. Export อาจมีเหตุผลหรือข้อความที่พิมพ์เอง ตรวจไฟล์ก่อนส่งต่อ. ชุด Export CDE ไม่รวมผังเกม ประวัติ maintenance หรือ architecture choices; สามบทเรียนมีสถานะแยกในเครื่อง

รองรับ browser รุ่นใหม่ที่มี Canvas, Pointer Events และ structuredClone. ยังไม่มีผลยืนยัน browser/mobile/screen-reader acceptance ครบทุกหน้า และไม่ได้อ้างว่าผ่าน WCAG. ไม่มี external runtime CDN หรือบัญชีที่ต้องลงชื่อเข้าใช้ในตัวแอป
